# Code of Conduct

## Our standard

This project is for people who want a small, honest tool for a video game. We want a calm place to talk about it.

Do:

- Be kind and patient. Many contributors are players, not programmers.
- Give a reason when you disagree. Criticize the idea, not the person.
- Accept that people have different skills, languages, and time.

Do not:

- Insult, harass, or threaten anyone.
- Post other people's private data. This includes player names and Riot IDs that you did not get permission to share.
- Ask for cheats, bots, memory reading, or tools that play the game for the user. We close these requests.
- Use sexual, hateful, or discriminatory language or images.

## Scope

This code applies to every place where the project talks: issues, pull requests, discussions, and any space where you speak for the project.

## Enforcement

The maintainer can edit or delete comments, close threads, and block people who break this code. To report a problem, write to drops.grizzly_67@icloud.com. The maintainer reads reports in private and keeps the reporter's name private.

If the maintainer is the problem, write to GitHub Support.
